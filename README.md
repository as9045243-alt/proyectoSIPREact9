# SIPRE - Sistema de Préstamo Escolar (Front-End)
SIPRE es una aplicación web enfocada en la gestión, control e inventario de préstamos de equipos y materiales escolares para instituciones educativas.
HTML5: para crear la estructura y contenido de las páginas web.
CSS3: para diseñar y dar estilo a las diferentes vistas del sistema.
Visual Studio Code: como entorno de desarrollo para escribir y organizar el código.
Git y GitHub: para llevar el control de versiones, almacenar el proyecto y trabajar de manera colaborativa.
Figma: para realizar el diseño y prototipo de las interfaces antes de su implementación.
Inteligencia Artificial: se utilizó como herramienta de apoyo principalmente para resolver dudas sobre el código y aprender el proceso para subir y administrar los archivos en el repositorio de GitHub.
CANVA: Para la documentacion y y organización de este documento trabajamos los integrantes en conjunto con esta herramienta, para hacer las tablas, y para que sea más facil organizar las capturas.
